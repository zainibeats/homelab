# Infrastructure Services

Platform services: dashboards, version control, and container management.

## Services Overview

### Dashboard
- **[Homepage (Public)](./homepage-public/README.md)** - Public dashboard of service status
- **[Homepage (Admin)](./homepage-admin/README.md)** - Administrator dashboard for internal services

### Container Management
- **[Watchtower](./watchtower/README.md)** - Automatic Docker container updates on a schedule
- **[Portainer](./portainer/README.md)** - UI for managing Docker containers, images, networks, and volumes

### Version Control
- **[Gitea](./gitea/README.md)** - Self-hosted Git service
