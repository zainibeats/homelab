# AI Agents

Context bundles (`AGENTS.md`, skills, MCP config) for AI agents such as Claude Code that run on my machines and work on external tools like the Obsidian vault. Nothing here is deployed by a Compose stack.

This is different from [`.agents/`](../.agents/), which holds the agent configuration for working on this repository itself.

- **[TaskNotes Obsidian](./tasknotes-obsidian/README.md)** - Claude Code context bundle for the Obsidian vault and its TaskNotes task management
- **[Inbox Processing](./inbox-processing/README.md)** - Skill that turns quick captures in the vault's `0-Inbox/` into tasks and notes
- **[CML Automation Lab](./cml-automation-lab/README.md)** - Skill that builds a Cisco Modeling Labs (CML-Free) lab for practicing network automation with Python and Ansible
