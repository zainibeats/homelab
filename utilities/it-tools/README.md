# IT Tools

A collection of handy online tools for developers and IT professionals. Includes encoders/decoders, formatters, converters, generators, and more — all running locally with no data leaving your network.

## Configuration

No environment variables are required. The service runs on port `8881` by default.

## Usage

Navigate to `http://<host>:8881` in your browser. All tools are available immediately with no login required.
