# Utilities

General-purpose utility services.

## Services Overview

- **[ConvertX](./convertx/README.md)** - File conversion with a web interface
- **[IT Tools](./it-tools/README.md)** - Online tools for developers and IT, such as encoders, formatters, and converters
- **[Yopass](./yopass/README.md)** - Self-hosted secret sharing with client-side encryption and expiring one-time URLs
- **[SearXNG](./searxng/README.md)** - Self-hosted metasearch engine
- **[Neko](./neko/README.md)** - Virtual browser streamed over WebRTC, with VPN integration
- **[Neko (OCI)](./neko-oci/README.md)** - CPU-encoded Neko for watch parties on the OCI host, reachable only over NetBird
- **[Wiki.js](./wiki-js/README.md)** - Documentation and knowledge base platform
- **[Matrix](./matrix/README.md)** - Private Matrix homeserver (Synapse) with Element Web and LiveKit calls, reachable only over NetBird
