# Skills

This directory contains custom skills for the coding agent.

## Available Skills

| Skill Name | Description |
| ----------- | ----------- |
| [`conventional-commits`](./conventional-commits/SKILL.md) | Write git commit messages following the Conventional Commits specification. |
| [`docs-health-check`](./docs-health-check/SKILL.md) | Audit and repair project documentation to accurately reflect the current codebase. |
| [`service-removal`](./service-removal/SKILL.md) | Guides the agent through the complete decommissioning of a service or feature from the homelab environment. |
