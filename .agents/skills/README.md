# Skills

This directory contains custom skills for the coding agent.

## Available Skills

| Skill Name | Description |
| ----------- | ----------- |
| `conventional-commits` | Write git commit messages following the Conventional Commits specification. |
| `docs-health-check` | Audit and repair project documentation to accurately reflect the current codebase. |
| `service-removal` | Guides the agent through the complete decommissioning of a service or feature from the homelab environment. |
